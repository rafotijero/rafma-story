# Presentación HTML: "Una RAFMA historia"

## Objetivo
Construir una presentación de diapositivas en un **único archivo HTML** (HTML + CSS + JS en el mismo archivo, sin frameworks). Se va a proyectar en una fiesta desde una laptop.

En esta etapa solo se construyen las diapositivas. **No** se incluye voz, música ni QR real; eso se agregará después.

## Requisitos
- Una diapositiva visible a la vez, a pantalla completa (16:9).
- Navegación: flecha derecha o clic para avanzar, flecha izquierda para retroceder.
- Transición suave (fade) entre slides.
- Cada slide tiene un `id` único (`slide-1` … `slide-15`), para poder asociarle audio más adelante.
- Estilo de cuento: tipografía legible y amigable, con colores cálidos y suaves.
- Diseño de cada slide: imagen arriba o al lado y texto narrado debajo o al costado.
- **Imágenes**: en lugar de imágenes reales, usa un recuadro de marcador con el texto `(Aquí va imagen N)`, donde N es el número de slide. Dejar la ruta prevista como comentario: `img/slide-N.png`.
- No agregues elementos que no estén en esta especificación.
